# General Manipulation instances without development rollouts: records

Report: Section 4.1 (protocol) and Appendix D. `../general_manipulation_timeline.md` gives the times.

The 96 such instances (12 of 20, or 6 of 10, per task) were fixed on 2026-11-02, before any General Manipulation
simulator run. They were first run in the post-freeze evaluation of the first version, whose records gave each
episode's score and a one-line failure class for the 59 below full credit. These records set the order of the fixes in
the second version, and the third also had the second's post-freeze records, so the 96 instances are held out for the
first version only. The platform job finished after the second version was frozen, and its task scores served only to
correct our local scoring of *pour*. During the development of the third version, a filter mistake let one summary list
program outputs (no scores) of *scoop* episodes on these instances. A latency test of the second version had run them.
The development record states that nothing from them was used.
